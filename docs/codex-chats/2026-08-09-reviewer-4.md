### Recommendation

**Reject in current form; encourage major revision/resubmission.**

There is a potentially publishable applied-methods result here: cumulative-map evaluation rewards persistence, and first-report frontier ranking is a more operational endpoint. The manuscript is unusually honest about non-dominance and presence-only limitations. It is not presently a publishable state-of-the-art model result, and the benchmark still has methodological defects that undermine its “geographic generalization” and holdout claims.

### Major findings

1. **The spatial analysis is not spatial validation.**  
   Models train using cells from every geographic block. `block_metrics()` merely calculates AP within blocks afterward. It therefore tests within-active-block ranking, not transfer to unseen geography. Latitude and longitude are explicit learned features, making this distinction particularly important.

   Blocks without positives are discarded. The 64 retained block-years cover only 4,536 candidate observations versus 9,223 candidates in the complete annual evaluations. This conditions the analysis on already-active regions and omits much of the operational error from prioritizing the wrong region.

2. **The “cluster bootstrap” is not clustered by geographic block.**  
   The 64 block-years arise from only 20 recurring blocks; ten blocks appear in all four years. Code resamples `(year, block)` rows independently, understating dependence across years within the same geography. Figure 2 also calls marginal intervals “paired cluster-bootstrap intervals,” whereas pairing is used only in the separate model-difference calculation.

3. **The reported artifacts no longer match the source.**  
   Results were generated at 16:33 and the PDF at 16:42. The shared solver was changed at 16:50 to add a Census land mask, no-flux edges, and finite-volume diffusion. The reported metrics came from the earlier periodic-boundary implementation. All metrics, figures, counts, and prose must be regenerated from a frozen source revision.

4. **The reaction–diffusion description is not sufficiently physical.**  
   The revised implementation improves the boundary condition, but the manuscript equation still describes a different update. Diffusion, growth, jump, and advection coefficients have no physical units, derivation, calibration, or sensitivity analysis. Gaussian smoothing with `sigma=4` is described as “sparse nonlocal transport jumps,” which is not an actual network-jump model. Grid convergence and timestep stability are not demonstrated.

5. **The partial 2026 slice is not an established holdout.**  
   The occurrence bundle was downloaded in August 2026, after all January–July outcomes were available. There is no timestamped preregistration, frozen model artifact, or pre-outcome prediction proving analyst-level isolation. The code avoids direct target-label fitting, but this is still a retrospective evaluation unless prior freezing can be documented.

6. **Temporal covariate leakage remains possible.**  
   The tree-of-heaven surface uses a current, undated GBIF sample for every historical fold. That allows observations acquired after an earlier forecast origin to influence that fold. The sample is also described as deterministic although an unversioned live API result order is not immutable.

7. **The headline numerical comparison is not apples-to-apples.**  
   The reported reduction from a legacy score near 0.90 to AP near 0.50 changes both endpoint and metric. It does not isolate the effect of cumulative-range leakage. Recompute the same metric on cumulative and frontier endpoints with the same predictions, including a persistence-only comparator.

8. **OG-RDE is not actually the highest annual-AP evaluated model.**  
   The no-reporting ablation has mean AP 0.512 versus OG-RDE’s 0.510. The manuscript later acknowledges this, but the abstract and conclusion say OG-RDE is highest/best. It can be called the best primary specification only if that distinction was predeclared and clearly stated.

9. **Data accounting is inaccurate.**  
   The bundle contains 62,791 records, but only 60,083 are both within the study domain and dated 2014–2026. Three records predate 2014 and 2,705 otherwise eligible-year records fall outside the grid. “The analysis uses 62,791 … dated 2014 through July 2026” is incorrect.

10. **No compelling superiority result exists.**  
    OG-RDE’s annual advantage over climate RD is only 0.009 AP and lacks a paired annual uncertainty analysis. It is worse than transport RD under the manuscript’s block aggregation, and a different model leads partial 2026. This supports a benchmark/negative-result paper, not a frontier-model or SOTA claim.

### Mandatory revisions by category

**Scientific significance / novelty — 6.0**

- Reframe the contribution as an evaluation benchmark and negative model-comparison result.
- Establish novelty against first-detection forecasting, survival/hazard models, point processes, PoPS, and established invasion-front evaluation—not only generic presence-only literature.
- Add strong baselines: learned hazard without physics, empirically fitted dispersal kernel, prior-year frontier model, and at least one established spread-model implementation.
- Isolate the cumulative-map leakage effect with an identical-metric experiment.
- Obtain a genuinely frozen prospective prediction or independent surveillance evaluation.

**Methodological rigor — 4.5**

- Freeze the solver and regenerate everything.
- Make the mathematical equation exactly match the finite-volume implementation.
- Document `dx`, `dy`, `dt`, coefficient units, boundary conditions, and numerical stability; perform grid/timestep sensitivity tests.
- Implement genuine network-mediated jumps or rename the Gaussian corridor process accurately.
- Select regularization, class weights, smoothing scales, and rank-fusion weights inside nested temporal training only.
- Use time-appropriate host covariates and document record-quality filtering, coordinate uncertainty, duplicates, domain truncation, and edge effects.

**Validation / statistics — 4.0**

- Perform buffered leave-region/block-out training and testing; post-hoc block aggregation is insufficient.
- Include inactive blocks through an operational global-budget metric instead of conditioning only on blocks containing positives.
- Cluster bootstrap by spatial block, or use an appropriate two-way spatial/temporal resampling method.
- Report paired uncertainty for annual AP and top-5% recall.
- Test sensitivity to block size/origin, grid resolution, target definition, and record cleaning.
- Rename 2026 “retrospective partial stress test” unless a pre-outcome frozen artifact can be produced.
- Add a complete-year or independent-survey validation.

**Clarity / figures — 7.0**

- Correct Figure 2’s bootstrap caption.

- Complete all references with authors, journal, volume/pages, and DOI; add GBIF, WorldClim, and Census citations.

**Reproducibility — 5.0**

### Strengths

- Rolling-origin feature construction is generally careful at the code level.
- Presence-only, causal, calibration, and partial-year limitations are stated candidly.
- AP and survey-budget recall are more appropriate than headline ROC AUC.
